# Changelog

## 1.2.0 — 2026-11-23
- First public release.
- `Ctrl + Shift + L` locks keyboard, mouse and touchpad; the screen keeps playing.
- Password unlock with wrong-password cooldown and countdown.
- Sign out / Task Manager / Shut down hidden from Ctrl+Alt+Del while locked.
- Settings window, start with Windows, high-DPI and multi-monitor support.
- Windows 10 (1607+) and Windows 11, 64-bit / 32-bit / ARM64.
